# VTEX Architecture Diagram

Interactive VTEX Constellation diagram for Solution Engineering presentations.

## Usage

Open `index.html` in a browser (double-click or drag into a tab). No build step required.

## Features

- Click any module to mark it as discussed during a session
- Toggle **Sales Channel** policies (B2B, B2C, Mercado Livre, WhatsApp) to highlight the relevant VTEX modules
- Reset button in the header clears all highlights and policy selections

## Notes

- **Mercado Livre** policy intentionally excludes Checkout and Payment Gateway — payment and checkout run on the external marketplace, not in VTEX
- Designed as a fixed-proportion slide canvas that scales to fit any viewport
